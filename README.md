# Python-AOI-UI
This as I call "Mask Generator" is a very useful tool to obtain the x1,y1,x2,y2 pixel coordinates of a ROI in a picture.
Clone this repo, and run the script on the interface select the picture and start drawing over the picture, once you create your rectangle/square you'll get a messagebox to name the ROI, once you save it you'll get the coordinates in a json file and a mask picture (binary with the ROI).
This mask is very useful for example for Anomalib Patchcore anomalies mask regions for training a custom model.
